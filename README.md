# CNY RUB Exchange

Сервис обмена китайских юаней (CNY) и российских рублей (RUB).

## Возможности

- Регистрация пользователей
- JWT авторизация
- Обмен CNY ↔ RUB
- История операций пользователя
- Автоматическое обновление курса валют
- PostgreSQL хранение данных
- Docker запуск

## Технологии

- Kotlin
- Spring Boot 4
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL 18
- Docker Compose
